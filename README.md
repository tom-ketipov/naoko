# Naoko

A document editor that behaves like a typewriter. You type onto paper held in a carriage: the paper slides left with every keystroke, a bell rings 7 characters before the right margin, the carriage locks at the margin, and Return slams it back. Every letter is inked a little differently, and documents are saved to your account like in Google Docs.

## Features

- **Carriage view**: the paper moves while the strike point stays still. There's a platen, a margin scale, a ribbon that lifts on every strike, and line/column/page counters.
- **Pages view**: the machine slides away so you can read and scroll the full sheets. Click anywhere on a sheet to move the carriage there.
- **Real typewriter rules**:
  - Backspace moves the carriage back, so typing over a letter **overstrikes** it.
  - Optional *correction tape* mode makes Backspace lift the last letter off instead.
  - Margin lock, or optional auto-return of whole words.
  - Tab stops every 5 columns. ↑/↓ (or the mouse wheel) rolls the platen. Home returns the carriage without feeding a line.
- **Two-colour ribbon** (black/red), two typefaces (Elite and Pica), four kinds of paper, single or double spacing, line widths from 50 to 80.
- **Synthesised sound** (Web Audio, no audio files): key strikes, a duller space bar, the carriage-return ratchet and slam, the margin bell and the paper feed.
- **Paste to auto-type**: pasted text gets typed out key by key.
- **Accounts and cloud saving**: autosave, a document list with templates (blank, letter, manuscript, poem), rename/delete, and read-only share links.
- **PDF export**: download a real PDF with one sheet per US Letter page. The typed letters keep their ink jitter and overstrikes, and an invisible text layer keeps the PDF searchable and copyable. Shared links can download the PDF too. You can also export as `.txt` or print.
- **PDF import**: drop a PDF on the documents page (or use the Import PDF card) to lay its text onto fresh sheets, or auto-type a PDF's text into the open document from the export menu. Scanned PDFs without selectable text can't be imported.

## Google Docs mirror

You can mirror any Naoko document into a real Google Doc in your Drive. Click the **Google Docs** button in the editor, connect your Google account once, and turn on **Mirror to Google Docs**. A couple of seconds after you stop typing, the Google Doc catches up.

- **One-way.** Naoko keeps the master copy. Edits made directly in Google Docs get replaced on the next sync.
- **Small updates.** Each sync sends only the changed stretch of text, so Google Docs version history stays readable and comments on untouched text survive.
- **Formatting.** Text is Courier Prime 12 pt (10 characters per inch), red ribbon stays red, and each typewriter sheet starts a new page. Overstrikes show the last letter typed.
- **Permissions.** Naoko asks only for the `drive.file` scope, so it can see and edit just the Google Docs it creates, never the rest of your Drive. Tokens are encrypted at rest with AES-256-GCM.

### Setting it up (one time, in Google Cloud)

1. Go to [console.cloud.google.com](https://console.cloud.google.com) and create a project, e.g. "Naoko".
2. Under **APIs & Services → Library**, enable the **Google Docs API** and the **Google Drive API**.
3. Under **APIs & Services → OAuth consent screen** (Google Auth Platform):
   - User type: **External**. Set the app name to "Naoko" and fill in your support email.
   - Data access / scopes: add `openid`, `.../auth/userinfo.email` and `.../auth/drive.file`.
   - Audience: while the app is in **Testing**, add your own Google account (and anyone else's, up to 100) as test users.
4. Under **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**.
   - Authorized redirect URI: `https://<your-render-domain>/api/google/callback`. For local development, also add `http://localhost:3000/api/google/callback`.
5. In the Render dashboard, open the `naoko` service → **Environment** and set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`. `TOKEN_ENC_KEY` is generated by the Blueprint; when running locally, set it to a random 32-byte value:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
   ```
6. Optionally set `GOOGLE_REDIRECT_URI` if your public URL differs from the host the server sees.

While the app is in Testing, Google shows an "unverified app" notice on the consent screen. Publishing it for everyone requires Google's brand verification. Because `drive.file` isn't a restricted scope, no security assessment is needed.

## Stack

- **Backend**: Node 20+ and Express (`server/`). Cookie sessions, bcrypt-hashed passwords, rate-limited auth, Helmet CSP.
- **Google**: OAuth 2.0 with offline access, plus the Docs and Drive REST APIs (`server/google.js`, `server/gdocs-mirror.js`).
- **Storage**: PostgreSQL when `DATABASE_URL` is set. Without it, a local JSON file at `data/naoko.json` (for development only).
- **Frontend**: plain ES modules with no build step (`public/`).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 and create an account.

## Deploy to Render

1. Push this folder to a GitHub/GitLab repo.
2. In Render, choose **New → Blueprint** and select the repo. `render.yaml` creates:
   - `naoko`, a Node web service (`npm start`, health check at `/healthz`)
   - `naoko-db`, a Postgres database whose `DATABASE_URL` is injected automatically
3. Deploy. The tables are created on first boot.

> On Render's free plan the local disk is wiped on every deploy, so production must use Postgres (the Blueprint sets this up). Free Postgres instances expire after a limited period, so upgrade the database plan to keep the data.

## Keyboard

| Key | Action |
| --- | --- |
| any character | strike a key |
| Return | carriage return + line feed |
| Backspace | carriage back one space (or lift off, in correction-tape mode) |
| Tab | next tab stop |
| ↑ / ↓, mouse wheel | roll the platen |
| ← / → | move the carriage without typing |
| Home | carriage return without a line feed |
| PageUp / PageDown | roll to the previous/next sheet |
| ⌘/Ctrl + S | save now |
